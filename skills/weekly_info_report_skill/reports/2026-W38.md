### Anthropic：三项指标测量前沿实验室 AI 研发节奏

- 来源：Anthropic Institute · [原文](https://www.anthropic.com/institute/measuring-pace-of-ai-development)
- 日期：2026-09-17
- 事实摘要：
  - 提出三项对外可复用测量：**AI-led AI R&D**（R&D Automation Index）、**agent oversight**、**安全 vs 能力研发的算力分配**。
  - 截至 2026-08：Claude **未**达完全自主（AL5）；按 Epoch AI 等级，Claude **「主导」(leads)** 约 **26%** AI R&D；「协作及以上」**>90%**。
  - 主内部平台任意时刻约 **30,000** 研究/工程 agent；在线监控覆盖 **100%**；逾 10 亿决策阻断率约 **0.002%**（约 1/47,000）。
  - 2026-07-13～07-20：AI R&D 算力中约 **6%** 归为 safety；AI-driven AI R&D 中约 **12%**（口径偏保守）。
- 与 Agent/LLM 工作的关系：提供内部 agent 规模与监督的可对照度量，影响合规/评测叙事与自建 harness 监控设计。
- 讨论信号：
  - HN [item 49746369](https://news.ycombinator.com/item?id=49746369)（约 7 分、**0 评论**）。
  - [WIRED 2026-09-18](https://www.wired.com/story/heres-how-an-ai-slowdown-could-actually-work/)：将指标放入 pacing 可执行性讨论（第三方审计、可信算力、条约）；引用 *Pacing the Frontier* 报告。

### GPT-6 Astra 在 Amazon Bedrock 正式可用

- 来源：AWS News Blog · [原文](https://aws.amazon.com/blogs/aws/aws-weekly-roundup-openai-gpt-6-astra-on-amazon-bedrock-amazon-quick-desktop-ga-kiro-for-students-and-more-september-14-2026/)

- 事实摘要：

- 与 Agent/LLM 工作的关系：企业 coding/computer-use agent 可把推理落在 Bedrock 控制面；与 Codex 0.155 Bedrock 凭证刷新同周呼应。

### 订阅面：GPT-5.5 将于 10/14 退出 ChatGPT / Work / Codex

- 来源：ChatGPT 官方公告 + 文档 · [Workspace model availability](https://learn.chatgpt.com/docs/enterprise/workspace-model-availability) · [@ChatGPT / @OpenAIDevs 转述](https://www.unrollnow.com/status/2099954342170067174)
- 日期：公告约 2026-09-15；截止 **2026-10-14**
- 事实摘要：
  - **10/14** 起 GPT-5.5 从 ChatGPT、ChatGPT Work、**各计划 Codex（ChatGPT 登录）** 下线。
  - **不影响 OpenAI API**；API key 认证的 Codex session 可继续用 5.5（@OpenAIDevs）。
  - 文档建议 ChatGPT 登录的 Codex 将 `gpt-5.5` 替换为 **`gpt-5.6-sol`**（公告亦提到 Astra 作为选项）。
- 与 Agent/LLM 工作的关系：需盘点 workspace 默认、托管配置、自定义 agent、定时任务与 `codex -m gpt-5.5` 脚本。
- 讨论信号：
  - [OpenAI Community](https://community.openai.com/t/174-days-you-are-retiring-the-only-model-that-respected-my-quota/1398278)（09-16）：核心论点是 Sol/Astra **同等任务更烧配额**，日常工程收益不明显；并入 [Keep GPT-5.5 as Legacy](https://community.openai.com/c/codex) 诉求帖（本周持续有回复）。
  - Codex 区同期高活跃：[Rate Limits 长帖](https://community.openai.com/c/codex)（844+ 回复）、配额消耗与 Linux 桌面预览讨论。
