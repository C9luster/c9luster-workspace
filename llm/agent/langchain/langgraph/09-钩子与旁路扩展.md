# 09 — 钩子与旁路扩展

> 本节只描述 LangGraph / `create_agent` 体系内的扩展点；不与其它脚手架对照。  
> LangGraph **核心 runtime 不提供** 独立的「hooks.json 生命周期总线」；扩展主要靠 **图内节点/边**、**callback**、以及上层 harness 的 **middleware**。

---

## 1. 先分清：主路径 vs 旁路

| 机制 | 是否决定「下一步去哪」 | 典型用途 |
|------|------------------------|----------|
| `StateGraph` 的 node / edge / `Command` / `Send` | **是**（主控制流） | ReAct 环、分支、扇出 |
| Checkpoint / interrupt（HITL） | **暂停/恢复主路径** | 人审、中断后续跑 |
| Callback | **否**（旁路） | 日志、trace、指标 |
| `create_agent` middleware | **可改请求/工具前后行为**（仍在 harness 约定内） | 摘要、护栏、工具包装 |
| 自定义包装 node | **是**（你把逻辑画进图） | before/after 工具、策略门 |

常见误解：把 callback 当成「改路由的 hook」。在本体系里，**改路由请改边或 Command**；callback 默认是观察与副作用。

---

## 2. Callback（旁路钩子）

LangChain/LangGraph 运行可挂 callback handler：在 LLM、工具、链/图步骤起止时收到通知。

**适合：** 日志、LangSmith 追踪、计数、调试打印。  
**不适合单独承担：** 业务策略门（应做成 node、middleware 或工具包装，以便状态可 checkpoint、行为可复现）。

可在 `invoke` / `stream` / 编译后 runnable 上传入 callbacks（具体 API 随版本以官方为准）。

---

## 3. Middleware（`create_agent` 轻 harness）

```text
Deep Agents                 ← 更厚默认栈
langchain.agents.create_agent ← 工具循环 + middleware
LangGraph                   ← runtime
```

`create_agent` 跑在 LangGraph 上，并用 **middleware** 在模型调用、工具调用等阶段插入可组合逻辑（例如摘要压缩、工具结果裁剪、护栏）。这是本生态最接近「可配置生命周期钩子」的一层，但仍是 **harness API**，不是核心 Pregel 的通用 hooks 注册表。

**可自定义：** 实现/组合官方或自研 middleware，在创建 agent 时挂入。  
**边界：** 约定在 agent 循环的固定插槽内；复杂多阶段业务仍更适合显式 `StateGraph`。

示意（API 名以当前 `langchain.agents` 文档为准）：

```python
from langchain.agents import create_agent

agent = create_agent(
    model,
    tools=tools,
    system_prompt="...",
    middleware=[...],  # 摘要、护栏、工具前后处理等
)
```

Deep Agents 则提供更厚的默认能力（规划、文件、子 Agent 等），同样可替换/扩展，底层仍是 LangGraph。

---

## 4. 图内「钩子感」：包装节点与 HITL

没有全局 hooks 文件时，等价扩展往往 **画进图**：

```text
… → policy_node（检查/改写）→ tool_node → audit_node → …
```

| 模式 | 做法 |
|------|------|
| 工具前策略 | 独立 node 读 state，deny 则 `Command` 走拒绝边 |
| 工具后处理 | tool 后接 node 做校验、格式化、写 Store |
| 人在环 | `interrupt` / 等待人输入后再 `Command` 续跑 |
| 子图 | 把一段带前后钩子的流程封成 subgraph |

这类扩展 **可被 checkpoint**，比纯 callback 更适合生产策略。

---

## 5. 能力边界一句话

| 你想做的事 | 在本体系怎么落 |
|------------|----------------|
| 日志 / 追踪 | Callback |
| Agent 循环内摘要、护栏、工具包装 | `create_agent` middleware 或 Deep Agents 扩展 |
| 强控分支、多阶段 SOP、可恢复策略门 | 显式 `StateGraph` 节点与边 |
| 任意「事件总线式」改写内部事件流 | **不是**核心卖点；需自建在图/状态上 |
