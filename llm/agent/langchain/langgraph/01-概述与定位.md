# 01 — 概述与定位

## 一句话定义

LangGraph 是一个**底层编排框架 / 运行时**，用来构建、管理、部署**长运行、有状态**的 Agent 与工作流。

定论（结合实践理解）：

> LangGraph 提供搭 Agent 的**模块与跑道**（循环、状态、恢复、HITL 等）；  
> Agent 细节（memory 策略、如何拼 LLM 请求、上下文压缩、业务工具语义）默认要**自己实现**，或选用更高层 harness 再改。

## 技术定位：三个关键词

| 关键词 | 含义 |
|--------|------|
| **Low-level orchestration** | 提供图计算式运行时，而不是固定 Agent 模板 |
| **Stateful / durable** | 状态可持久化，失败与中断后可从检查点恢复 |
| **Multi-actor** | 多节点、可并行、可动态派发（`Send`）的多 Actor 工作流 |

官方描述（README）：

> Low-level orchestration framework for building stateful agents.

安装：

```bash
pip install -U langgraph
# 或
uv add langgraph
```

## 它解决什么问题

LangGraph 为「任意长运行、有状态的 workflow / agent」提供基础设施：

| 能力 | 说明 |
|------|------|
| Durable execution | 故障后从离开的位置继续跑 |
| Human-in-the-loop | 任意节点可中断，人工检查 / 修改状态后再继续 |
| Memory（管道） | Checkpoint 短期 + Store 长期接口；**策略不内置** |
| Streaming | 节点 / 消息级流式事件 |
| Production deployment | 配合 LangSmith Deployment / CLI 部署 |

## 它不是什么

- **不是**「装完就能聊天的完整产品」——需要自己定义图或用更高层 API
- **不是**开箱即用的完整业务 Agent 大脑（上下文策略、prompt 工程仍要你做）
- **不是**必须安装完整 `langchain` 包——可不用高层 Agent API，但硬依赖 `langchain-core`
- **不是** JS 版本体——JS/TS 在独立仓库 [LangGraph.js](https://github.com/langchain-ai/langgraphjs)

## 与 LangChain / Agent 建设的真实关系（v1）

常见误解：「LangGraph 已经不依赖 LangChain，自己就能建完整 Agent。」

更准确：

| 事实 | 说明 |
|------|------|
| Node 可以是普通函数 | 不必把「LangChain Agent 对象」当 node |
| 仍依赖 `langchain-core` | 消息、`BaseChatModel`、`BaseTool`、`Runnable` 等 |
| 高层工厂迁回 LangChain | `create_react_agent` 已弃用，推荐 `langchain.agents.create_agent` |
| Agent 跑在 LangGraph 上 | `create_agent` / Deep Agents 的 runtime 是 LangGraph |

```text
Deep Agents              ← agent harness（开箱能力最多）
        ↑
langchain.agents.create_agent  ← 更轻的 harness + middleware
        ↑
LangGraph runtime        ← 耐久执行 / 流式 / HITL / checkpoint
        ↑
langchain-core           ← 消息、模型、工具抽象
```

经验法则：

- 只要「模型 + 工具循环」→ `create_agent` / Deep Agents
- 要「确定性流程 + Agent 节点混用、人工卡点、严格恢复」→ 手写 `StateGraph`
- 要改 memory / 上下文 / prompt 细节 → **无论哪一层，策略仍在你这边**（上层最多给默认 middleware）

## 生态位置

```text
Deep Agents          ← 更高层：规划 / 子 Agent / 文件系统 / 部分上下文能力
        ↑
create_agent         ← LangChain 推荐的 Agent 工厂（底层 LangGraph）
        ↑
LangGraph            ← 本仓库关注的编排运行时
        ↑
langchain-core       ← Runnable、消息、工具等基础抽象
        ↔
LangSmith            ← 观测、评估、部署
```

## 设计灵感

| 来源 | 借鉴点 |
|------|--------|
| Google Pregel | 以超步（superstep）推进的图计算模型 |
| Apache Beam | 流水线 / 持久化执行思路 |
| NetworkX | 面向用户的图构建 API 风格 |

## 版本与成熟度

- 核心包名：`langgraph`
- 版本量级：`1.x`（PyPI classifiers 为 Production/Stable）
- Python：`>=3.10`
