# 02 — 仓库结构与包依赖

## 仓库形态

LangGraph 官方仓库是 **Python / JS 混合的 Monorepo**：真正可发布的库都在 `libs/`，示例在 `examples/`。

```text
langgraph/
├── libs/                 # 正式发布的包
│   ├── langgraph/        # 核心框架
│   ├── prebuilt/         # 高层 Agent / Tool API
│   ├── checkpoint/       # Checkpointer 抽象 + 内存等
│   ├── checkpoint-postgres/
│   ├── checkpoint-sqlite/
│   ├── checkpoint-conformance/
│   ├── cli/              # langgraph CLI
│   ├── sdk-py/           # Python SDK（Server API）
│   └── sdk-js/           # JS/TS SDK
├── examples/             # 多 Agent、RAG、HITL、ReAct 等
├── docs/
├── Makefile              # 对各 libs 统一 lint / format / test / lock
├── AGENTS.md             # 贡献 / Agent 改代码约定
└── README.md
```

根目录 `Makefile` 会遍历 `libs/*`，在各子包内执行 `make lint|format|test` 与 `uv lock`。

## 各包职责

| 包 | PyPI / 角色 | 一句话 |
|---|---|---|
| **langgraph** | `langgraph` | `StateGraph` / Pregel 核心运行时 |
| **prebuilt** | `langgraph-prebuilt` | `create_react_agent`、`ToolNode` 等；通常随主包安装 |
| **checkpoint** | `langgraph-checkpoint` | Checkpointer / Store / Cache 接口与基础实现 |
| **checkpoint-postgres** | `langgraph-checkpoint-postgres` | Postgres 持久化 |
| **checkpoint-sqlite** | `langgraph-checkpoint-sqlite` | SQLite 持久化 |
| **cli** | `langgraph-cli` | 本地开发、Docker 构建与部署 |
| **sdk-py** | `langgraph-sdk` | 调用 LangGraph Server REST API |
| **sdk-js** | `@langchain/langgraph-sdk` 一类 | 浏览器 / Node 侧对接 Server |

## 依赖关系（生产依赖视角）

来自仓库 `AGENTS.md` 的依赖图：

```text
checkpoint
├── checkpoint-postgres
├── checkpoint-sqlite
├── prebuilt
└── langgraph

prebuilt
└── langgraph

sdk-py
├── langgraph
└── cli

sdk-js (相对独立)
```

核心包 `langgraph` 的 `pyproject.toml` 典型依赖（版本以本地为准）：

- `langchain-core`
- `langgraph-checkpoint`
- `langgraph-sdk`
- `langgraph-prebuilt`
- `xxhash`、`pydantic`

开发时 monorepo 用 `uv.sources` 把兄弟包指到本地 editable path。

## 核心包内部目录（读代码用地图）

```text
libs/langgraph/langgraph/
├── graph/          # StateGraph、消息图、分支
├── pregel/         # 执行引擎（最重）
├── channels/       # LastValue / Topic / Delta 等
├── func/           # 函数式 @entrypoint / @task API
├── stream/         # 流式相关
├── managed/        # 托管值
├── types.py        # Command / Send / Interrupt / RetryPolicy ...
├── runtime.py
└── ...
```

`prebuilt` 侧常见模块：

```text
libs/prebuilt/langgraph/prebuilt/
├── chat_agent_executor.py   # create_react_agent
├── tool_node.py
├── interrupt.py
└── ...
```

`checkpoint` 侧常见模块：

```text
libs/checkpoint/langgraph/
├── checkpoint/     # base、memory、serde
├── store/
└── cache/
```

## examples 覆盖的模式

`examples/` 适合对照学习，常见主题包括：

- multi_agent、plan-and-execute、rag
- human_in_the_loop、reflection / reflexion
- lats、llm-compiler、rewoo、code_assistant
- chatbots、web-navigation、customer-support

## 工程约定（改源码时）

在对应 `libs/<pkg>` 目录下：

```bash
make format
make lint
make test
# 或指定文件
TEST=path/to/test.py make test
```

文档与注释约定：不要用 Sphinx 风格的双反引号 `` ``code`` ``，行内代码用单反引号。
