# 09 — 特性与模式索引

本章索引 Claude Code 主要 Feature 与运行模式，说明 Agent 层面的行为差异。Feature 通常由构建时 feature() 宏 + GrowthBook 远程配置 + 环境变量三层门控。

---

## Feature 门控三层

| 层 | 作用 |
|----|------|
| 构建时 feature() | 外部构建默认 false，内部构建按 MACRO 注入 |
| GrowthBook | 远程 A/B、allowlist、渐进发布 |
| 环境变量 | 用户/会话级显式开关 |

---

## 核心 Agent 模式

### Coordinator Mode

| 项 | 说明 |
|----|------|
| 启用 | FEATURE_COORDINATOR_MODE=1 + CLAUDE_CODE_COORDINATOR_MODE=1 或 /coordinator |
| 主线程 | 只编排：Agent(worker)、SendMessage、TaskStop |
| Worker | 标准工具 + MCP + Skill，强制 async |
| 通信 | task-notification XML + SendMessage(agentId) |
| 恢复 | session JSONL mode entry + matchSessionMode |
| 典型场景 | 复杂 bug 调查→实现→验证，主脑综合 |

### Agent Teams / Swarm

| 项 | 说明 |
|----|------|
| 启用 | 默认开启；CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS_DISABLED 关闭 |
| 入口 | TeamCreate → Agent(name) → TaskCreate |
| 通信 | mailbox by name、shared task list |
| Teammate | in-process（同进程 runner）或 pane-based（独立终端） |
| 典型场景 | 长期并行、队友持续领任务 |

### Fork Subagent

| 项 | 说明 |
|----|------|
| 启用 | FORK_SUBAGENT feature（默认关闭） |
| 触发 | Agent({}) 省略 subagent_type |
| 特点 | 继承父上下文 + exact tools，强制 async |
| 禁用 | coordinator、non-interactive |
| 典型场景 | 并行探索、prompt cache 复用 |

### Remote Agent

| 项 | 说明 |
|----|------|
| 触发 | isolation: "remote"（内部构建） |
| 本地 | RemoteAgentTask + sidecar meta |
| 执行 | CCR 远端 sidecar |
| 恢复 | 取决于 CCR session 状态 |

### Worktree Isolation

| 项 | 说明 |
|----|------|
| 触发 | isolation: "worktree" 或 agent definition |
| 行为 | 临时 git worktree，文件改动隔离 |
| 优化 | 已存在 worktree 时跳过 fetch，近零延迟恢复 |

| 变量 | 作用 |
|------|------|
| CLAUDE_CODE_COORDINATOR_MODE=1 | 进入 Coordinator |

## 端到端场景对照

### 场景 A：修复复杂 Bug（Coordinator）

```text
用户提 bug → Coordinator 拆任务
  → Agent(worker) × N 异步调查/实现/验证
  → task-notification 回主线程
  → Coordinator 综合（非转发）
  → SendMessage 修正方向或 fresh worker
  → 汇总用户
（无 TeamCreate，无 shared task list）
```

### 场景 B：长期并行（Swarm）

```text
TeamCreate → TaskCreate × N
  → Agent({ name: "researcher" }) 等
  → teammate 认领 TaskUpdate
  → mailbox 通信
  → idle → 继续 TaskList
  → TeamDelete graceful shutdown
```

### 场景 C：一次性专家任务（Subagent）

```text
Agent({ subagent_type: "code-reviewer", prompt: "..." })
  → sync: tool_result 当前 turn
  → async: task-notification 下一 turn
```

### 场景 D：并行探索（Fork）

```text
Agent({ prompt: "分析方案 A" })  // 无 subagent_type, fork gate on
  → async_launched
  → 继承父上下文 parallel 分析
  → task-notification
```

## Agent 层面技术特点总结

1. **Terminal-native Agentic Loop**：while(true) 逐步循环，非一次性规划批量执行
2. **Streaming-first**：流式 API + 流式工具进度 + 并行 StreamingToolExecutor
3. **动态上下文管道**：每 turn 预处理 + 三层压缩 + System Prompt 动态组装
4. **工具即能力**：50+ 内置 + MCP 统一 Tool 接口，每次 API 调用动态组装
5. **权限即边界**：8 层规则 + Plan Mode + 沙箱 + Hook 拦截
6. **多 Agent 正交**：Subagent / Fork / Coordinator / Swarm / Remote 五条路由并存
7. **Append-only 持久化**：JSONL + uuid 链 + sidechain 隔离 + compact 投影
8. **Prompt 即扩展**：Skills 和 Custom Agent 以 Markdown 声明能力，非硬编码
9. **可组合接入**：REPL 人机交互、SDK 程序化、ACP 编辑器协议
10. **Provider 抽象**：7 种 API Provider 统一 Stream 事件层

## 常见集成误区

| 误区 | 正确理解 |
|------|----------|
| 模型按任务难度自动选 Coordinator/Swarm | Coordinator 需用户显式开启；Swarm 是模型按需建 team |
| Swarm teammate = subagent | teammate 走 spawnTeammate，长生命周期 + mailbox |
| 磁盘 transcript = 模型上下文 | compact/microcompact 投影后模型只见子集 |
| Feature 默认全开 | 外部构建 feature() 默认 false，需 MACRO/GrowthBook/ENV |
| BackgroundAgentSelector 列所有后台任务 | 仅 backgrounded LocalAgentTask |
