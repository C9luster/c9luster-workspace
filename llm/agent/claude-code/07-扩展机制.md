# 07 — 扩展机制

Claude Code 的可扩展性围绕四条主线：**自定义 Agent**、**Skills**、**Hooks**、**MCP**。它们共同定义 Agent 的能力边界、工作流和生命周期拦截。

---

## 自定义 Agent

### 三种来源（优先级从低到高）

| 来源 | 位置 |
|------|------|
| Built-in | 内置硬编码 agent |
| Plugin | 插件注册 |
| User/Project/Policy | .claude/agents/*.md 或 settings.json |

getActiveAgentsFromList 按 agentType 去重，**后者覆盖前者**。可在项目中放 Explore.md 完全替换内置 Explore。

### Markdown Agent 完整格式

```yaml
---
name: reviewer
description: Code review specialist
tools: Read,Glob,Grep,Bash
disallowedTools: Write,Edit
model: haiku          # 或 inherit
effort: high
maxTurns: 10
permissionMode: plan
background: true
initialPrompt: /search TODO
isolation: worktree   # 或 remote（内部）
memory: project
mcpServers: [slack]
hooks: { PreToolUse: [...] }
skills: code-review
color: blue
---
正文 = agent system prompt
```

### 加载流程

```text
loadMarkdownFilesForSubdir('agents')
  → 解析 frontmatter + 正文
  → 校验 name/description
  → 并行 loadPluginAgents
  → 合并 + 分配颜色
```

### 与 AgentTool 联动

派生时按 tools/disallowedTools 过滤；requiredMcpServers 等待连接（最长 ~30s）；runAgent 挂载 SubagentStart hooks、preload skills、agent memory、sidechain transcript。

## Skills 技能系统

### 五个来源

| 来源 | 说明 |
|------|------|
| Built-in Commands | 硬编码 70+ 斜杠命令（/commit、/review、/compact） |
| Bundled Skills | 编译时打包，延迟解压 reference files |
| 磁盘 Skills | skill-name/SKILL.md 目录格式 |
| MCP Skills | MCP server prompt 转换，禁止内联 shell |
| Legacy Commands | /commands/ 向后兼容 |

磁盘加载路径（优先级）：policy → user → project（向上遍历）→ --add-dir

### Frontmatter 关键字段

```yaml
name, description, when_to_use
allowed-tools, argument-hint, arguments
model, effort, context: inline|fork
agent, user-invocable, disable-model-invocation
version, paths（条件激活）, hooks, shell
```

### 两条执行路径

**Inline（默认）**
- Prompt 注入为 UserMessage，主对话流继续
- contextModifier：合并 allowedTools 到 alwaysAllowRules、模型/effort 覆盖
- 处理 $ARGUMENTS、!`shell`、${CLAUDE_SKILL_DIR}、${CLAUDE_SESSION_ID}

**Fork（context: fork）**
- executeForkedSkill 在独立子 Agent 执行
- 不阻塞主线程，完成后 task-notification
- 适合重型分析、大上下文隔离

### 预算感知

Skill 描述在 system prompt 中有 token 预算，bundled skill 描述不可截断；when_to_use 供 AI 自动匹配。

## Hooks 生命周期

### 27 种 Hook 事件（节选）

| 阶段 | 事件 |
|------|------|
| 会话 | SessionStart, SessionEnd, Setup |
| 用户 | UserPromptSubmit, Stop, StopFailure |
| 工具 | PreToolUse, PostToolUse, PostToolUseFailure |
| 权限 | PermissionRequest, PermissionDenied |
| 子 Agent | SubagentStart, SubagentStop |
| 压缩 | PreCompact, PostCompact |
| 协作 | TeammateIdle, TaskCreated, TaskCompleted |
| MCP | Elicitation, ElicitationResult |
| 环境 | ConfigChange, CwdChanged, FileChanged, WorktreeCreate/Remove |

### 6 种 Hook 类型

| 类型 | 执行方式 |
|------|----------|
| command | Shell 脚本 |
| prompt | 注入 AI 上下文 |
| agent | 启动子 Agent |
| http | HTTP 请求 |
| callback | 内部 JS（SDK） |
| function | 运行时注册（Agent/Skill 内部） |

### 执行引擎要点

- 变量替换：${CLAUDE_PLUGIN_ROOT}、${CLAUDE_PROJECT_DIR} 等
- stdin 写入 JSON 输入
- 默认超时 10 分钟
- 支持 async: true 首行标记异步 hook
- PreToolUse 可返回 deny/ask/updatedInput

### Hook 与 Agent Loop 交互

- Stop hook preventContinuation → 终止 loop
- Stop hook 阻塞错误 → stop_hook_blocking 继续 loop
- PreCompact/PostCompact → 压缩前后自定义逻辑
- SubagentStart → 修改子 Agent 启动上下文

## MCP 配置

### 配置来源合并

```text
settings.json mcpServers
.mcp.json（项目级）
插件 manifest
claude.ai connectors
enterprise managed-mcp.json
SDK 传入（IDE 嵌入）
内置 dynamic（computer-use, chrome, vscode）
```

getAllMcpConfigs：enterprise 独占或合并多源。

### 连接状态

connected | failed | needs-auth | pending | disabled

useManageMcpConnections React Hook 管理生命周期；connectToServer memoize 缓存。

### 认证

OAuth 等需 needs-auth 状态，用户完成认证后 reconnect。

### Agent 级 MCP

Agent definition 可声明：
- requiredMcpServers：启动前必须可用
- mcpServers：agent 专属 server，生命周期跟随子 Agent

## 插件系统（概要）

插件可注册：Agent、Skill、MCP server、Hooks。命名空间前缀避免冲突（如 plugin::agent-name）。

## 扩展机制协作示例

**代码审查 Skill + 自定义 Reviewer Agent + PreToolUse Hook**

```text
用户: /code-review src/
  → SkillTool inline 注入审查 prompt + allowedTools
  → 或 Agent({ subagent_type: "code-reviewer" })
  → PreToolUse hook 写 audit log
  → Reviewer 用 Read/Grep 分析
  → PostToolUse hook 通知 Slack（MCP）
  → 结果回主线程或 task-notification
```

## 扩展设计哲学

| 机制 | 扩展什么 |
|------|----------|
| Custom Agent | **角色与工具边界** |
| Skill | **工作流 Prompt** |
| Hook | **生命周期拦截与审计** |
| MCP | **外部系统能力** |

四者正交：Agent 定角色，Skill 定流程，Hook 定守卫，MCP 定集成。
