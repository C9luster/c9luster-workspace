## 默认组合中常见的开启项

`dsh-base` 供 `web`、`headless`、`sdk` 与 `acp` 共享，包含模型适配器、工具、JSONL 持久化、检查点策略、沙箱与审批、设置、凭据和遥测。压缩、重复工具提醒和工具超时在基础组合中默认启用。Agent Teams 与计划模式按配置挂载。

`sdk-minimal` 刻意不包含 `dsh-base`、压缩、文件系统工具、工作区指令、技能、后台任务和子 Agent。它只公布按平台选择的持久 shell，并使用不受限的沙箱策略。

## 入口形态

| Profile | 形态 |
|---------|------|
| `web` | 浏览器应用 |
| `headless` | 不带服务器的一次性运行 |
| `sdk` | JSON-RPC，供 TypeScript 与 Python SDK |
| `sdk-minimal` | 精简 SDK 运行时 |
| `acp` | 仅自动化的 ACP 服务器 |
| `desktop` | Electron Host，默认端口 `19387` |
