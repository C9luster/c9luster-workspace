# 07 — 扩展机制

DeepSeek Harness 的扩展以 Cordis 插件为单位。原生扩展点是类型化事件和 `ctx` 服务。`hooks` 组另外把现有的 Claude Code 或 Codex command hook 接到这些事件上。

---

## 原生扩展点

产品里没有单独的特权内核。新行为挂到已有事件或服务上，插件卸载时撤销注册。

| 目标 | 机制 |
|------|------|
| 模型提供方 | 在 `ctx.llm` 注册适配器 |
| 面向模型的工具 | 在 `ctx.tools` 注册；schema 进入提示词组装 |
| 拦截请求、工具或轮次 | `agent/*` 或 `tools/*`。`agent/turn-stopping` 可以阻止轮次结束 |
| 注入模型可见上下文 | `agent.inject()`，落入下一次获准的请求并写入日志 |
| 用户命令 | `ctx.commands`，不经过模型 |
| 持久事实 | 扩展 `SessionEventMap` |
| 单个 Agent 的注册 | 该 Agent 的 `agent.ctx` |
| 不同的能力集合 | Agent preset；服务行使用 `isolate` realm |

Waterfall 监听器必须调用 `next()` 才能把决定交给后续监听器。只提供上下文的逻辑先委托，再把消息折进下游决定，因此后面的监听器仍可以拒绝或改写。

自修改运行时由 extensions 组提供只读 API 发现，以及进程内的 host/client runner。持久安装走 Plugin Manager。Creator 模式写入的是已安装插件，不是临时改写循环源码。

## Hooks 桥接

`dsh-hook-protocol` 是共享引擎。两个插件按来源工具的 command hook 子集执行已有配置：

| 插件 | 配置 | 支持的事件 |
|------|------|------------|
| `dsh-hooks-claude-code` | Claude Code `hooks.json` 或 settings 中的 `hooks` | `SessionStart`、`UserPromptSubmit`、`PreToolUse`、`PostToolUse`、`Stop`、`SubagentStart`、`SubagentStop` |
| `dsh-hooks-codex` | Codex `hooks.json` | `SessionStart`、`UserPromptSubmit`、`PreToolUse`、`PostToolUse`、`Stop`。跳过 `async: true` 和非 command 钩子 |

映射到 harness 事件：

| Hook | Harness 事件 | 能力 |
|------|----------------|------|
| `SessionStart` | `agent/created` 初始化 | 附加会话上下文。Claude Code 桥接上此发射不等待 |
| `UserPromptSubmit` | `agent/pre-step` | 阻断提示词，或附加上下文 |
| `PreToolUse` | `tools/pre-execute` | 阻断工具。Claude Code 侧可请求批准 |
| `PostToolUse` | `tools/post-execute` | 带反馈阻断结果，或附加上下文 |
| `Stop` | `agent/turn-stopping` | 通过 `steer()` 强制再执行一步 |
| `SubagentStart` / `SubagentStop` | `subagent/start` / `subagent/end` | 仅 Claude Code 桥接。start 向同进程子级附加上下文；stop 只观测 |

同一事件上匹配的钩子按配置顺序串行执行。决策折叠与顺序无关，最严格者为 `deny`，然后是 `ask`，然后是 `allow`。配置读失败时记录警告并不运行钩子，Agent 仍会启动。单条钩子命令失败会被记录，运行继续。

`transcript_path` 留在载荷中以保持兼容，Claude Code 桥接写空字符串，Codex 桥接写 `null`。持久化层不把压缩会话文件交给钩子脚本读取。超出该 command hook 子集的行为应写成原生插件。

## Skills

技能提供方注册到 `ctx.skills`。`tool-skill` 是模型侧 Consumer：发布目录，并用 `skill` 工具加载正文。用户 `/name` 手势注入同一份 `<skill_content>`。`disable-model-invocation` 的技能不出现在目录和工具中，只能由用户手势进入。

正文没有单独的大小上限。目录描述会被截断。
