# 02 SFT 训练配置

## 1. 环境准备

### 硬件要求

| 模型规模 | Full SFT | LoRA SFT |
|----------|----------|----------|
| 7B | 1× A100 80G | 1× RTX 4090 24G |
| 14B | 2× A100 80G | 1× A100 40G |
| 32B | 4× A100 80G | 2× A100 80G |
| 70B+ | 8× A100 80G + DeepSpeed | 4× A100 80G |

### 依赖安装

```bash
# LLaMA-Factory（推荐入门）
git clone https://github.com/hiyouga/LLaMA-Factory.git
cd LLaMA-Factory && pip install -e ".[torch,metrics]"

# 或 ms-swift（推荐生产）
pip install ms-swift -U

# Flash Attention（强烈推荐）
pip install flash-attn --no-build-isolation
```

## 2. LLaMA-Factory 训练

### 2.1 LoRA 微调（推荐起步）

创建 `examples/train_lora/coding_agent.yaml`：

```yaml
### model
model_name_or_path: Qwen/Qwen2.5-Coder-32B-Instruct
trust_remote_code: true

### method
stage: sft
do_train: true
finetuning_type: lora
lora_rank: 64
lora_alpha: 128
lora_target: all
lora_dropout: 0.05

### dataset
dataset: coding_agent_sft
template: qwen
cutoff_len: 32768
max_samples: 100000
overwrite_cache: true
preprocessing_num_workers: 16

### output
output_dir: ./output/coding-agent-lora-v1
logging_steps: 10
save_steps: 200
plot_loss: true
overwrite_output_dir: true

### train
per_device_train_batch_size: 1
gradient_accumulation_steps: 8
learning_rate: 1.0e-5
num_train_epochs: 3.0
lr_scheduler_type: cosine
warmup_ratio: 0.1
bf16: true
ddp_timeout: 180000000

### eval
val_size: 0.05
per_device_eval_batch_size: 1
eval_strategy: steps
eval_steps: 200
```

启动：

```bash
llamafactory-cli train examples/train_lora/coding_agent.yaml
```

合并 LoRA 权重：

```bash
llamafactory-cli export \
  --model_name_or_path Qwen/Qwen2.5-Coder-32B-Instruct \
  --adapter_name_or_path ./output/coding-agent-lora-v1 \
  --template qwen \
  --finetuning_type lora \
  --export_dir ./output/coding-agent-lora-v1/merged \
  --export_size 2 \
  --export_device cpu
```

### 2.2 Full SFT（大规模数据）

```yaml
finetuning_type: full
```

## 3. ms-swift 训练

### 3.1 单卡 LoRA

```bash
swift sft \
  --model Qwen/Qwen2.5-Coder-32B-Instruct \
  --model_type qwen2_5 \
  --train_type lora \
  --dataset ./data/coding_agent_train.jsonl \
  --torch_dtype bfloat16 \
  --num_train_epochs 3 \
  --per_device_train_batch_size 1 \
  --learning_rate 1e-5 \
  --lora_rank 64 \
  --lora_alpha 128 \
  --gradient_accumulation_steps 8 \
  --max_length 32768 \
  --output_dir ./output/coding-sft-v1 \
  --warmup_ratio 0.1 \
  --save_steps 200 \
  --logging_steps 10 \
  --attn_impl flash_attn \
  --gradient_checkpointing true \
  --bf16 true
```

### 3.2 多卡 Full SFT + DeepSpeed ZeRO-3

```bash
NPROC_PER_NODE=8 \
swift sft \
  --model Qwen/Qwen2.5-Coder-32B-Instruct \
  --model_type qwen2_5 \
  --train_type full \
  --dataset ./data/coding_agent_train.jsonl \
  --deepspeed zero3 \
  --max_length 32768 \
  --per_device_train_batch_size 1 \
  --gradient_accumulation_steps 4 \
  --learning_rate 5e-6 \
  --num_train_epochs 2 \
  --save_steps 100 \
  --output_dir ./output/coding-sft-full-v1 \
  --attn_impl flash_attn \
  --use_liger true \
  --bf16 true
```

## 4. 超参数参考

### Coding Agent 推荐值

| 参数 | LoRA | Full SFT | 说明 |
|------|------|----------|------|
| learning_rate | 1e-5 ~ 2e-5 | 5e-6 ~ 1e-5 | Full 用更低 lr |
| num_train_epochs | 2~5 | 1~3 | 小数据集多 epoch，大数据集少 epoch |
| lora_rank | 32~128 | — | 64 是常用起点 |
| cutoff_len / max_length | 16384~32768 | 32768 | 匹配 Agent 上下文长度 |
| batch_size × accum | 8~32 | 32~128 | 有效 batch size |
| warmup_ratio | 0.05~0.1 | 0.1 | |
| weight_decay | 0.01 | 0.01 | |

### 学习率选择

```
数据量 < 1K    → lr=2e-5, epoch=5, LoRA
数据量 1K~5K   → lr=1e-5, epoch=3, LoRA/Full
数据量 5K~20K  → lr=5e-6, epoch=2, Full
数据量 > 20K   → lr=2e-6, epoch=1, Full + cosine decay
```

## 5. 训练监控

### WandB / TensorBoard

LLaMA-Factory 自动支持，在 yaml 中添加：

```yaml
report_to: wandb
run_name: coding-agent-sft-v1
```

ms-swift：

```bash
--report_to wandb \
--run_name coding-agent-sft-v1
```

### 关键指标

| 指标 | 正常范围 | 异常信号 |
|------|----------|----------|
| train loss | 持续下降 | 不下降 → lr 太低或数据格式错误 |
| eval loss | 跟随 train loss | eval 上升 → 过拟合，减 epoch 或加数据 |
| grad_norm | 0.1~10 | >100 → 梯度爆炸，降 lr |
| tokens/sec | 视硬件而定 | 突然下降 → 检查数据加载 |

## 7. 常见问题

### Loss 不下降

1. 检查数据格式是否正确（ShareGPT role 映射）
2. 检查 template 是否匹配模型（Qwen 用 `qwen`，DeepSeek 用 `deepseek`）
3. 尝试提高 learning_rate 一个数量级
4. 确认 cutoff_len 未截断关键 tool_calls

### OOM（显存不足）

1. 降低 `per_device_train_batch_size` 到 1
2. 增大 `gradient_accumulation_steps`
3. 启用 `gradient_checkpointing`
4. 使用 LoRA 代替 Full SFT
5. 降低 `cutoff_len`（如 16384）
6. 使用 DeepSpeed ZeRO-3 / FSDP

### 训练后 tool calling 能力退化

1. 检查训练数据中 tool_calls 比例（应 > 60% 样本含 tool use）
2. 降低 epoch 数，避免过拟合到简单回复
3. 混合 10~20% 通用对话数据
4. 确认推理时启用了 tool calling 解析器

## 8. Checkpoint 选择

```
训练过程中 save 多个 checkpoint
    ↓
在验证集 / benchmark 上逐个测试
    ↓
选择 eval loss 最低 或 benchmark 得分最高的 checkpoint
    ↓
合并 LoRA（如适用）→ 部署
```

不要默认使用最后一个 checkpoint，后期可能过拟合。
